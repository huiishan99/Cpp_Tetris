# Capture Media

The README currently uses `docs/gameplay-preview.svg`, a stylized preview that
can be rendered without launching the Win32 game. Replace it with a real
screenshot or GIF after a Windows playtest.

## Screenshot

1. Run `.\build.bat`.
2. Launch `.\main.exe`.
3. Play until the board shows active pieces, hold, next queue, and score.
4. Press `Win + Shift + S` and capture the game window.
5. Save the image as `docs/gameplay-screenshot.png`.
6. Update the README image path from `docs/gameplay-preview.svg` to
   `docs/gameplay-screenshot.png`.

## GIF

1. Record a short 8-12 second clip with Xbox Game Bar or ScreenToGif.
2. Show start, gameplay, line clear, F1 settings, and game over if possible.
3. Save as `docs/gameplay-demo.gif`.
4. Keep the file reasonably small before committing.
